*Project Description*

A simple web application that allows users to enter their personal information through an HTML form and displays the submitted information on a JSP page.

*Technologies Used*

HTML, CSS, Java, Servlet, JSP, Apache NetBeans

*Instructions*

1. Open the project in Apache NetBeans.

2. Right-click the project (PersonalProfile) and select Run.

3. Open the application in the web browser.

4. Fill in the profile form and click Submit Profile to view the result.
